# Rust Learning Projects

This repository contains tiny Rust projects demonstrating various concepts for learning Rust.

## Structure

Each concept is in its own folder under `concepts/`:

- `basics/` - Variables, data types, functions, control flow
- `ownership/` - Ownership
- `borrowing/` - Borrowing and references
- `lifetimes/` - Lifetimes
- `structs/` - Structs and enums
- `traits/` - Traits and shared behavior
- `error_handling/` - Error handling with Result
- `collections/` - Vectors and HashMaps
- `concurrency/` - Threads and basic concurrency

## Running the Projects

Navigate to any concept folder and run:

```bash
cargo run
```

Each project has a README explaining the concepts covered.
